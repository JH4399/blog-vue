# 拾光 Field Notes

基于现有 Vue 3 + Vite + Pinia + Vue Router 项目实现的简洁博客前端，接口对应 `C:/blog` 中的 Spring Boot 后端。包含独立管理后台与配套用户管理后端扩展。未启动业务后端、数据库或 Redis；真实联调由你运行。

## 启动与联调

需要 Node.js 22.18+（或 24.12+）和 npm。

```powershell
cd C:\blog-vue
npm install
npm run dev
```

访问终端输出的地址，默认是 http://localhost:5173。后端由你自行启动，当前后端配置端口为 **2233**。前端默认向 `/api` 发请求，Vite 将请求原样代理到 `http://localhost:2233`，开发时不需要修改后端 CORS。

后端在其他地址时，在前端项目根目录创建 `.env.local`，或复制示例配置：

```powershell
Copy-Item .env.example .env.local
```

```dotenv
VITE_API_BASE_URL=/api
API_PROXY_TARGET=http://localhost:2233
VITE_DEMO_MODE=false
```

修改环境变量后重新启动 Vite。`API_PROXY_TARGET` 填写后端源地址，不要追加 `/api`。`VITE_API_BASE_URL` 也可以填完整 API 地址，此时由后端配置允许前端域名的 CORS。

首页未登录时会显示登录入口；点击“浏览示例”可查看明确标注的本地只读示例。示例不会自动替代失败的接口数据，也不会向真实后端写入。设置 `VITE_DEMO_MODE=true` 可在启动时直接进入示例模式；登录真实账户会自动退出示例模式。

## 已实现

- 首页：精选文章、文章卡片/列表切换、搜索、分类和标签筛选、状态筛选、排序、分页。
- 登录与注册：使用真实接口，保存 Bearer Token，刷新后查询当前用户，401 清理登录态，退出时撤销服务端 Token。
- 阅读页：Markdown 基础排版、目录跳转、文章标签、评论与回复、删除评论、编辑和删除文章。
- 写作页：Markdown 编辑/预览、正文图片插入、封面上传或 URL、摘要、分类、标签、置顶、草稿/发布/私密状态；按用户保留浏览器本地草稿。
- 归档、友情链接、关于页面、404 页面、手机布局和深色模式。
- 个人资料：从账户菜单进入 `/profile`，用户修改本人的昵称、邮箱、头像和简介；支持上传自定义头像、预览、更换和移除。
- 独立管理员后台：数据概览、所有文章及作者与互动统计、用户列表及账户状态管理、分类、标签、友链和系统配置维护。
- 加载、空数据、错误提示和重试；封面为空或无法加载时使用本地 CSS 插画，无需外部图片服务。

## 与后端一致的行为

| 前端功能 | 使用的接口 |
| --- | --- |
| 登录、注册、当前用户、退出 | `/api/user/login`、`register`、`me`、`logout` |
| 修改本人资料（登录） | `PUT /api/user/{id}`，仅提交昵称、邮箱、头像、简介 |
| 用户管理（管理员） | `GET /api/user`、`PUT /api/user/{id}/status`，修改仅提交 `status` |
| 文章新增、修改、删除及管理详情（登录） | `/api/posts`、`/api/posts/{id}` |
| 图片上传（登录，multipart 字段 `file`） | `POST /api/uploads/images` |
| 图片查看（公开，直接返回图片） | `GET /api/images/{year}/{month}/{name}` |
| 文章列表（游客及登录用户） | `GET /api/posts` |
| 公开阅读及有效浏览统计 | `GET /api/public/posts/{id}` |
| 分类、标签 | `/api/categories`、`/api/tags` 及 `/{id}` |
| 文章标签关联 | `/api/post-tags?postId=…`、`/api/post-tags`、`/api/post-tags/{postId}/{tagId}` |
| 查看评论（游客及登录用户） | `GET /api/comments?postId=…` |
| 发表评论、回复及删除（登录） | `POST /api/comments`、`DELETE /api/comments/{id}` |
| 友情链接 | `/api/links?status=1`（展示）；`/api/links` 及 `/{id}`（管理） |
| 系统配置 | `/api/settings` 及 `/{id}`（管理员） |

响应统一解包 `{ code, message, data }`，请求使用 `Authorization: Bearer <accessToken>`。

首页和归档统一调用 `GET /api/posts`，游客无需登录即可浏览、搜索和翻页；匿名请求时后端始终只返回 `status=1` 且未删除的公开文章，传入草稿或私密状态参数也不能扩大范围。登录后使用同一接口并携带 Bearer Token，普通用户可以查看本人文章及他人已发布文章，管理员可以查看全部。

点击文章进入阅读页后调用 `GET /api/public/posts/{id}`；登录时携带 Bearer Token，由后端按账号识别读者。草稿和私密文章仅作者或管理员可预览，使用原 `/api/posts/{id}`，编辑器也继续使用此接口。退出或登录过期后会清空受保护文章，当前列表切换为游客内容。

文章列表按页返回，搜索、分类、标签（`tagId`）、状态筛选和排序通过参数交给后端处理，每页 10 条。标签筛选在数据库分页前执行，总数和分页均为筛选后的结果，无需游客访问受保护的标签关联接口。示例模式仍使用本地筛选。

游客无需登录即可查看文章评论，发表评论和回复仍需登录；退出登录后会重新获取游客可见评论。评论提交后立即可见，当前后端不返回评论状态字段，前端不展示审核状态。删除带回复的评论、被引用的分类/标签时，显示后端返回的冲突提示。

文章 PUT 会提交完整可编辑字段，保留草稿/私密和空字段语义，不提交作者、统计、发布时间等服务端字段。文章保存与标签关联分两步完成；标签同步失败会说明文章已保存，重试使用已生成 ID，避免重复创建。

编辑器支持基础 Markdown 标题、段落、加粗、斜体、列表、引用、代码块、图片和 HTTP(S) 链接。原始 HTML 作为文本展示，不执行；暂未实现 HTML 富文本、Markdown 表格、普通附件上传或点赞。系统配置页管理后端配置记录，页面品牌文案目前在前端维护。

写文章及后台编辑共用图片功能：点击“上传封面”上传并预览封面，可更换或移除；点击工具栏“插入图片”，上传后在正文光标处插入 Markdown，预览和阅读页均显示图片。支持 JPEG、PNG、WebP，单张最大 5 MB；上传期间暂停编辑和保存，失败保留已有内容并允许重试。上传请求携带 Bearer Token，由浏览器生成 multipart boundary；保存文章仅提交返回的图片路径，不提交文件或 Base64。`/api/images/...` 自动匹配 `VITE_API_BASE_URL`，兼容默认代理及独立后端域名。

图片查看接口无需登录，图片可见性不随文章草稿、私密或删除状态变化。“移除”仅清空文章封面引用，后端当前没有图片删除接口。

## 自行验证联调

1. 启动后端及其数据库和 Redis，启动前端。
2. 注册账户后登录；新账户文章列表为空时，点击“写文章”。
3. 填写标题和正文，保存草稿；再编辑并发布，确认状态和详情同步。
4. 测试分类筛选、搜索、归档、刷新页面后的登录恢复。
5. 在详情页评论或回复，确认提交后立即显示且没有审核状态标签；测试删除评论。
6. 管理员账户登录后可从导航进入“管理”，维护分类、标签、友链和配置，再测试文章分类与标签绑定。
7. 退出后确认文章不再展示；令牌过期后应提示重新登录。

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:2233;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;

    try_files $uri $uri/ /index.html;
}
```

## 独立管理后台

管理员登录后点击导航“管理”，或直接访问 `/manage`。后台采用独立侧栏和页面布局：

- `/manage`：文章总量、用户总量、浏览总数、点赞总数及最近文章。
- `/manage/posts`：全部未删除文章，展示作者、分类、状态、浏览数、点赞数、评论数和日期；支持搜索、作者/分类/状态筛选、按浏览或点赞排序、分页、编辑和软删除。
- `/manage/posts/new`、`/manage/posts/:id/edit`：在后台新建和编辑文章，保存后返回文章管理。
- `/manage/users`：查看用户资料、角色、账户状态、文章数量；仅能启用/禁用其他账户，不能修改资料或角色。
- `/profile`：普通用户及管理员均可修改本人昵称、邮箱、头像和简介，保存后同步当前登录用户资料。头像复用 `POST /api/uploads/images`，支持 JPEG、PNG、WebP，最大 5 MB；上传完成后预览，点击“保存资料”才将地址写入本人资料。上传期间禁止重复上传、保存和重置，失败保留原头像；支持上传、更换和移除头像，不提供手动填写地址的输入框。账户菜单、首页资料卡和后台用户列表显示自定义头像，地址为空或图片加载失败时显示昵称首字。表单按接口限制校验长度和邮箱，空字段保存为 `null`；用户名、密码、角色、状态不可编辑。
- `/manage/categories`：新增、编辑、删除分类；设置名称、别名、描述与排序值。
- `/manage/tags`：新增、编辑、删除标签；设置名称和别名。
- `/manage/links`、`/manage/settings`：友链和系统配置维护。

用户列表 `GET /api/user` 和状态修改 `PUT /api/user/{id}/status` 仅管理员可访问。列表返回 `data: { records, total, page, size, pages }`，每条用户资料包含 `postCount`。本人资料修改使用 `PUT /api/user/{id}`，仅可修改当前登录用户本人；完整提交 `nickname`、`email`、`avatar`、`bio`，空值清空字段。两个修改接口均返回更新后的用户资料对象。登录仍读取 `data.accessToken` 和 `data.user`，当前用户及注册读取 `data` 中的用户资料，退出成功返回 `data: null`。

只有后端确认的管理员可以进入后台。用户数据和文章数据在退出、降级或切换账户后清除，过时请求不会重新填入私有数据。当前管理员不能禁用自己，用户管理不提供角色修改。前端角色检查用于界面控制，用户管理权限同时由后端逐请求验证。

浏览、点赞、评论统计均显示后端返回值。正式阅读调用公开详情接口，由后端统计有效浏览并返回最新 `viewCount`；前端同步当前缓存卡片上的浏览数，不自行加 1。点赞仍仅展示，后端尚无点赞操作接口。用户文章数为该用户的未删除文章数。

`backend-extension/` 是早期独立用户管理接口的历史快照，当前后端已整合这些功能，无需再次安装。前端 API 封装统一映射到新地址，用户管理页与作者筛选框共用此映射。本次只修改前端。已核对后端源码和运行中服务的 OpenAPI：用户字段、登录结构及分页结构与前端兼容，用户管理请求地址已更新。新增测试覆盖注册、登录、当前用户、退出及新地址下的分页和修改请求。


## 统一错误弹窗

后端接口错误、字段校验、网络中断、请求超时、响应格式错误，以及 Vue 运行异常、未处理的 Promise 拒绝和路由加载错误，统一通过全局弹窗展示。原页面的重试按钮仍可使用，成功操作保持轻提示。

错误弹窗位于独立的 Vue 根节点，并使用原生模态 dialog，可以显示在管理页编辑框之上；支持键盘操作、深色主题和手机屏幕。相同异常在多层捕获时只显示一次，并发的相同错误合并，点击“知道了”或按 Esc 关闭。文章保存后标签同步失败会保留已保存的文章 ID 并提供明确提示。

新增错误处理入口为 `src/services/errors.js`，弹窗组件为 `src/components/ErrorDialog.vue`。后续新增业务捕获使用 `reportError(error)`，补充业务说明使用 `reportError(error, { message: "说明" })`，保留原异常对象以便去重。后端继续通过原有统一异常处理返回 JSON 错误，本次无需调整后端接口。

验证：前端 16 项测试及生产构建通过；实际后端、数据库和 Redis 联调由使用者运行。

## 列表接口适配与按需分页

文章、用户、分类、标签、友情链接、系统配置列表通过各自现有 list 接口请求分页数据，固定每页 10 条，翻页再加载。搜索、筛选、排序由后端执行。作者/分类名和用户文章数随当前页返回。

- 文章：`GET /api/posts?page=1&size=10`
- 用户：`GET /api/user?page=1&size=10`
- 分类、标签、友链、配置：`GET /api/categories`、`/api/tags`、`/api/links`、`/api/settings`，参数同上。

以上六类接口始终返回 `data: { records, total, page, size, pages }`，省略分页参数也返回第一页。前端通过 `api.list(resource, { page, ...filters })` 调用并校验分页结构，展示 `records`、使用 `total` 显示总数。空结果允许 `total=0, pages=0`，不显示“1 / 0 页”；超过末页时，前端保留筛选条件并最多补发一次末页请求，空列表回退第 1 页。退出、切换筛选或离开页面后，旧响应不会覆盖新数据。评论及文章标签关联仍按数组读取。

文章列表返回封面 coverImage、标题、创建时间、分类名和统计字段，不返回正文、摘要和发布时间；首页网格、列表视图及归档均展示已有封面，不生成虚假的阅读时长；打开文章或编辑时通过详情接口获取完整内容。详情中的分类及标签若不在当前选项页，按 ID 补查。普通用户可查看本人文章及他人已发布文章；用户管理和配置仅管理员可用；分类/标签/友链保持公开查询。

首页、归档和友链支持后端分页，分类与标签侧栏也可以翻页。作者和分类筛选框可搜索、逐页查找；普通用户和管理员编辑文章时，分类和标签均按需分页。概览通过 `/api/posts/summary` 查询全站统计和最近 10 篇文章，不受当前页影响。后台初始化只读取身份，切回博客时再加载博客内容。

本次仅适配前端，未修改后端。当前后端使用 MyBatis-Plus 分页，完整接口说明见 `C:\blog\docs\list-pagination.md`。请自行运行后端、数据库和 Redis。

旧的`backend-pagination/`保留为历史快照，安装脚本已停用，当前不提供`/api/admin/pages/*`。实际达梦数据库与Redis联调由使用者运行。

## 文章请求时机

应用初始化及登录仅准备身份和公共数据；首页、归档页挂载后按当前筛选请求文章列表，避免初始化和页面挂载各请求一次。直接访问文章详情、写作页或其他页面不会预加载文章列表。手动刷新、翻页及筛选变更仍按需请求；删除后页码超出范围时允许补查末页。

## 阅读与浏览量

阅读页在身份初始化完成后加载一次公开详情，避免登录恢复触发重复阅读请求。游客不请求需要登录的评论及文章标签关联，评论区显示登录入口。登录用户打开未缓存的草稿/私密直达链接时，公开接口返回 404 后才回退到受保护详情；已知草稿/私密文章直接预览。401、403 或统计服务 503 不自动降为匿名访问或改用管理接口，统一弹窗提示。示例模式不发送阅读请求。

浏览去重由后端负责：同账号或匿名 IP 对同篇文章每 24 小时计一次，已登录作者本人不计数。编辑和管理详情不计数。前端回归覆盖匿名阅读、恢复登录后只请求一次、草稿预览、最新计数展示、示例及错误处理；实际数据库与 Redis 计数由使用者联调。

## 文章列表封面

列表直接使用 `GET /api/posts` 当前页记录中的 `coverImage`，支持上传接口返回的 `/api/images/...` 及 HTTP(S) 地址。未设置封面时只展示文字；不逐篇请求文章详情，不触发阅读计数。本次在 `C:\blog` 的 `PostListVO` 和分页 SQL 中补充封面字段，无需数据库迁移；后端需重新启动后才会返回新字段。

文章首页默认图文列表，封面位于右侧，使用细分隔线及随内容变化的高度；可切换为网格卡片。标题、分类、作者、日期和统计按层次展示，不为缺失摘要或封面预留空框。封面加载失败时回到文字排版。首页文章区域随页面自然滚动，分页紧跟文章，不再使用固定高度的内部滚动区域；手机单列，平板将个人资料移至列表下方。
